# SEO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add on-page/technical SEO to the proTutor360 single-page site — full `<head>` metadata, `robots.txt`, `sitemap.xml`, `EducationalOrganization` JSON-LD structured data, and a heading-hierarchy fix.

**Architecture:** Next.js App Router metadata APIs. Root `Metadata` export in `app/layout.tsx` covers the whole site (there's only one route, `/`). `app/robots.ts` and `app/sitemap.ts` are generated route handlers per Next.js file conventions. JSON-LD is a plain `<script type="application/ld+json">` rendered in the layout body.

**Tech Stack:** Next.js 16 App Router metadata conventions (`Metadata` type, `MetadataRoute.Robots`, `MetadataRoute.Sitemap`), TypeScript. No test framework in this repo — verification is via `tsc --noEmit`, `next build`, and manual `curl`/view-source checks.

Spec: `docs/superpowers/specs/2026-08-16-seo-design.md`

### Task 5: Fix footer heading level

**Files:**
- Modify: `app/components/Footer.tsx:68`

The document's heading order is `h1` (Hero) → `h2`/`h3` through every section, ending with `h2` in `About`. The footer's column headers use `h4`, which skips `h3` — a heading-hierarchy violation.

- [ ] **Step 1: Change the tag**

In `app/components/Footer.tsx`, change:

```tsx
                <h4 className="text-xs font-bold uppercase tracking-wider text-white">
                  {col.title}
                </h4>
```

to:

```tsx
                <h3 className="text-xs font-bold uppercase tracking-wider text-white">
                  {col.title}
                </h3>
```

(Only the tag name changes — the Tailwind classes are utility classes with no tag-specific styling, so visual output is unaffected.)

- [ ] **Step 2: Type-check**

Run: `npx tsc --noEmit`
Expected: no errors

- [ ] **Step 3: Commit**

```bash
git add app/components/Footer.tsx
git commit -m "fix(seo): use h3 for footer column headers to preserve heading order"
```
